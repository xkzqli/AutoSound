# AutoSound

Vehicle audio classification using pretrained CLAP embeddings,
engineered audio features, and an ExtraTrees classifier.

Developed by Kai Rui Li with AI assistance.

## Results

**80.6% test accuracy: 58 of 72 recordings classified correctly.**
Test macro-F1: 0.794.
Selected configuration training cross-validation macro-F1: 0.811.

Three dataset categories:
- Engine Issue
- Non engine issue
- Normal engine

297 recordings were inspected. Removing one unusable recording and
eight exact duplicate copies left 288: 216 training and 72 testing.

The test split was repeatedly evaluated during development.
Results are exploratory, not an untouched final evaluation.

## Features

Upload audio, predict a category, inspect waveform and frequency spectrum,
retrieve similar training recordings, and download a JSON report.
Only the first 30 seconds are analyzed.

## Model

Frozen CLAP embeddings are combined with frequency-band statistics,
MFCC, delta, delta-delta, log-mel, and spectral statistics.
The final ExtraTrees classifier uses 700 trees, max_features=0.3,
min_samples_leaf=1, balanced class weights, and random_state=42.

## Installation

Python 3.12 on Windows:
1. Run: py -3.12 -m venv .venv
2. Install CPU PyTorch:
   .venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
3. Install dependencies:
   .venv\Scripts\python.exe -m pip install -r requirements.txt
4. Download the pretrained encoder once:
   .venv\Scripts\python.exe -c "from transformers import ClapModel, ClapProcessor; n='laion/clap-htsat-unfused'; ClapProcessor.from_pretrained(n); ClapModel.from_pretrained(n)"

## Run

.venv\Scripts\python.exe -m streamlit run app_v5.py

Open http://localhost:8501 and keep the terminal running.
The included classifier does not require retraining.
The app loads CLAP from its local download cache.
Only load trusted joblib model files.

## Reproduce experiments

With the same source audio and folder structure, run these scripts in order:
1. scripts/train.py
2. scripts/train_v3.py
3. scripts/train_clap.py
4. scripts/train_final.py
5. scripts/train_v5.py

Use .venv\Scripts\python.exe followed by each script path.
Later steps depend on artifacts and caches generated by earlier steps.
Saved metrics and split records document the reported experiment.

## Limitations

This is an engineering prototype, not a validated automotive diagnosis.
Labels and source independence have not been verified.
Some recordings may be synthetic audio, sound effects, or motorcycles.
Exact deduplication does not remove all near-duplicates.
Overlap with CLAP pretraining data is unknown.
Non-vehicle audio can still receive a category prediction.
A normal prediction does not establish vehicle safety.
